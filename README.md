# Web Request Journey

## Website
YouTube

## About the Project

This project explains what happens when I type
youtube.com in my browser and press Enter.

It follows the request from the client to YouTube's
infrastructure and explains how the response comes back
to the browser.

## Request Journey

The main steps are:

1. The browser acts as the client.
2. DNS helps find the IP address of the website.
3. The request travels through the network and the Internet.
4. The request reaches YouTube's infrastructure.
5. The server processes the request.
6. A response is sent back to the browser.
7. The browser displays the website.
